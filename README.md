# Xingwen Li · 李幸文

Personal research homepage for Xingwen Li, Huawei HiSilicon · Turing.

Website — https://followdeep.github.io/

Contact — lixingwen5@huawei.com

The site contains a research introduction, current interests, and contact information. It uses static HTML, CSS, and SVG.

Edit `index.html` to update the content and `styles.css` to update the layout. GitHub Pages serves the `main` branch from the repository root.

For a local preview, run `python3 -m http.server 8765 --bind 127.0.0.1` from this directory and open `http://127.0.0.1:8765/`.
